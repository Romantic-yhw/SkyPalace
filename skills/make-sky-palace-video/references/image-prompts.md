## 输出目标

为每个镜头写一条可独立使用的完整提示词。提示词必须使未读过上下文的生成模型也能理解画面，同时复述需要跨镜锁定的事实。默认生成单张关键帧，不生成多格分镜拼图。

提示词使用一个连续段落。中文负责精确关系，少量英文只用于补充通用摄影风格，不用关键词堆砌替代叙述。

## 单段语法

按以下顺序自然连接：

```text
输出约束 → 世界与真实度 → 核心奇观 → 四层空间 → 建筑结构 →
人物连续性 → 摄影机 → 构图比例 → 光线与空气 → 色彩与材质 → 失败规避
```

每一部分必须描述可观察的关系。不要只写“更仙、更美、更震撼、史诗感、8K”。

## 十一段语义顺序

### 1. 输出约束

明确单张、画幅、无解释、无文字。例如：

```text
请只生成一张横向16:9图片，不解释，不输出任何文字、边框或分镜格。
```

### 2. 世界与真实度

写清东方神话、电影摄影、超写实和原创建筑语汇：

```text
电影级超写实东方神话史诗摄影，真实建筑受力与天然材质，不是游戏概念图。
```

### 3. 核心奇观

用一整句写主语、动词和宾语：

```text
直径数千公里的巨月内部裂开一座实体白玉天门，门洞深处仍有九重宫阙。
```

随后补充绝对尺度、相对尺度和出框方式。主奇观只有一个。

### 4. 四层空间

- 前景：写被裁切的遮挡物及其占比或位置。
- 中景：写可行走地面、人物和方向。
- 远景：写主奇观的结构与遮挡关系。
- 极远景：写天体、第二世界或终点。

用天路、河道、阶梯、光带或视线把至少三层连起来。

### 5. 建筑结构

按承载层→竖向层→连接层→冠部层描述。说明台基厚度、柱距、斗拱、重檐、门洞深度、桥面宽度和山基岩层。不要罗列一串没有受力关系的建筑名词。

### 6. 人物连续性

复述人数、服装、发型、左右位置、朝向和动作。把极小人物作为第一尺度参照：人物高度通常只占画面 0.25%–0.8%，关键巨物镜头优先 0.3%–0.6%，人物必须小于门钉、栏杆局部、桥面石板尺度或柱身铆钉，只保留服装色块、双人轮廓和行走方向。除非用户明确要求人物近景，人物超过 1% 即重做。人物前方仍须保留至少画面宽度 30% 的无遮挡连续行动路径，脚下存在真实接触面。

### 7. 摄影机

明确：

- 机位相对人物与地面的高度。
- 14–22mm 广角或特殊镜头的焦段理由。
- 仰拍、平视或轻微俯拍的角度。
- 单点、中央、偏置或引导线透视。
- 深景深、建筑垂直线和是否允许轻微镜头畸变。

### 8. 构图比例

写入可检查区间：

- 巨构占比：45%–65%，至少一处出框，优先让顶部和一侧同时超出画框。
- 有效留白：28%–42%，保留空气层次。
- 行动区：下方约 22%–32%。
- 连续路径：人物前方至少画面宽度 30%。

这些比例是语义区域，可存在遮挡关系，不要求机械相加为 100%。

### 9. 光线与空气

指定时间、主光方向、轮廓光、檐下暗部、云层受光面、薄雾位置和体积光来源。虹彩只在逆光与水雾交汇处少量出现。避免无来源金光和纯白过曝。

### 10. 色彩与材质

选择三到四个主色和一个点睛色。描述冷白玉的灰纹与磨损、深朱木的旧漆与顺纹、暗金构件的低反射、巨岩地层、湿石面、水膜和云层厚度。

### 11. 失败规避

将失败规避自然合并在段尾，不拆出“负面提示词”：

```text
保持门柱笔直、桥面连续、倒影方向准确和人物身份稳定，避免满屏宫殿、密集浮岛、普通景区牌坊、欧美城堡、日本神社、科幻结构、塑料CG、纯白雾墙、霓虹、紫色法术、人物过大、重复人物、畸形肢体、错误透视、文字、水印和标志。
```

只列与当前镜头有关的高风险失败，避免无穷枚举。

## 摄影与构图参数

| 目的 | 机位与焦段 | 构图 |
| --- | --- | --- |
| 巨物压迫 | 离地 40–80cm，14–20mm，轻微仰拍 | 巨构贴近一侧并出框，人物极小 |
| 辽阔朝圣 | 人物后方 15–30m，20–28mm，平视或微俯 | 天路曲线穿过云海，终点在远方 |
| 仪式抵达 | 中央低机位，18–24mm | 两侧局部框景，中央通向第二世界 |
| 无人天体奇观 | 远距离 35–70mm 或广角大全景 | 白鸟、窗格、山峰、天体构成尺度链 |
| 镜海空间 | 离水面 30–60cm，18–22mm | 倒影占下半幅，少量巨柱框景 |

不要随意同时写超广角、长焦压缩、微距和航拍。

## 人物和无人场景

有人场景优先背向或侧背镜头，让身体方向服务路径。极小人物只需用墨青、月白和朱砂色块保持身份，以迈步、停在门槛、仰望或披风被风牵引表达方向。不要让远景人物摆复杂手势，也不要为了看清服饰而放大人物；建筑不合理的宏大必须先于人物细节被读到。

无人场景删除人物动作与行动区要求，但仍保留视觉通道，并使用白鸟→窗格→山峰→天体的四级尺度链。不要生成空旷却无法判断尺度的风景。

## 建筑与物理真实性

- 水必须有流向、河床或出口；倒流用飞沫和高光方向证明。
- 浮空大陆必须有厚重山基，不是薄石片。
- 月轮必须有球体明暗和被云遮挡关系，不是平面圆盘。
- 门洞必须有厚度、内壁和落影。
- 台阶、桥面和栏杆的透视必须共同收敛到同一消失点。
- 倒影与真实物体的位置、光向和水纹一致。

## 可复制模板

将花括号替换为本镜可观察事实，最终删除花括号和字段名并合成一段：

```text
请只生成一张{画幅}图片，不解释、不输出文字或分镜格。以电影级超写实东方神话史诗摄影表现{时间与地点}，真实建筑受力与天然材质，不是游戏概念图；{核心奇观主谓关系}，其{绝对尺度与相对尺度}，{出框延伸方式}。前景{裁切遮挡物与视差线索}，中景{连续地面、极小人物身份服饰、动作方向与画面占比0.25%–0.8%}，人物小于{门钉、栏杆局部或柱身铆钉}并只保留清晰色块与轮廓，人物前方保留至少画面宽度30%的无遮挡连续路径，远景{主奇观结构}，极远景{天体或第二重世界}，并以{四级尺度链}证明尺度。建筑从{承载层}到{竖向层、连接层、冠部层}结构清楚；摄影机位于{位置与高度}，使用{焦段}、{俯仰与透视}、深景深且建筑垂直线稳定。主巨构约占{45%–65%}并至少一处出框，天空、云海、镜面或远山形成{28%–42%}有效留白，行动区约占下方{22%–32%}。{主光方向、体积光来源、云雾层次}，以{主色与点睛色}表现{材质细节}，整体{情绪词不超过三个}；保持{本镜稳定项}，避免{与本镜有关的结构、风格、人物和文字失败}。
```

## 自检

- 是否能用一句主谓关系说清奇观？
- 是否能在画面中指出四级尺度链？
- 人物是否只有画面 0.25%–0.8%，并且明显小于门钉或栏杆局部？
- 是否明确前景、中景、远景和极远景？
- 巨构是否至少一处出框？
- 留白是否有空气层次而非雾墙？
- 有人物时，是否存在无遮挡连续路径？
- 建筑、水和天体是否遵守自身物理逻辑？
- 是否复述跨镜连续性，而不是写“同上一镜”？
- 是否只有一个段落且无模型参数冲突？
