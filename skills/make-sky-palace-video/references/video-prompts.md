## 输出原则

一张通过质检的关键帧对应一个独立视频片段。每镜只写一个无空行的单段提示词，把需要发生的运动与必须保持稳定的内容同时写入；不要分成“正向提示词、负面提示词、运镜参数”三个区块。

巨构应当稳定。奇观的生命感主要来自摄影机、前景遮挡、云、水、光、衣袂和白鸟，而不是让整座宫殿、月轮或浮空大陆无意义晃动。

## 单段运动语法

```text
首帧锁定 → 摄影机轨迹 → 人物动作 → 分层环境运动 →
视差 → 揭示节拍 → 结束状态 → 连续性与防漂移
```

提示词描述一条可以执行的时间线，不同时要求推进、后退、环绕、俯冲、变焦和甩镜。

## 八段语义顺序

### 1. 首帧锁定

开头写：

```text
以输入图片为唯一首帧和视觉基准，锁定……
```

列出主奇观轮廓、建筑结构、人物身份服饰、光向、道路与关键留白。不要只写“保持画面一致”。

### 2. 摄影机轨迹

说明起点、方向、速度、路径、俯仰变化和结束位置。每镜一个主运动、最多一个辅助运动：

- 缓慢前移＋轻微抬头：发现门、巨柱或天体。
- 横向滑移＋越过遮挡：揭示巨构宽度。
- 侧后方跟随＋柔和弧线：人物穿越天路。
- 缓慢升高＋保持焦段：抵达后看见第二世界。
- 几乎静止＋极小呼吸式推进：无人奇观。

禁止数字变焦替代真实位移，除非模型只能支持变焦。

### 3. 人物动作

动作数量控制在一个主动作和一个细节动作：慢走并抬头、停步并望向门内、向前走且披风被风掀起一次。写明脚掌接触、步幅、身体朝向、不露脸和结束姿态。远景人物不用手指、拔剑、转身等复杂连续动作。

### 4. 分层环境运动

按前中远排序并使用不同速度：

- 前景雾、松枝、桥栏和飞尘速度最快。
- 中景衣袂、浅水、近云和天河中速。
- 远景云海、白鸟和光束低速。
- 月轮、宫殿、山体和浮空大陆保持刚性稳定。

水流方向必须与奇观关系一致；逆流天河的飞沫、高光和雾气都向上。

### 5. 视差

明确前景快速、中景中速、远景近乎静止的速度递减。摄影机横移时至少让一个前景遮挡物滑出画面，主奇观只产生合理的相对位移，不发生形变。

### 6. 揭示节拍

用秒数或百分比设定：

- 前 25% 建立人物与方向。
- 25%–60% 越过遮挡或改变仰角。
- 60%–85% 完整读出不可能关系，达到峰值。
- 最后 15% 稳定停留，不用爆光收尾。

5 秒片段通常只需要一次揭示。更长片段可以在 70% 左右加入光线或白鸟的次级事件，但不新增第二主奇观。

### 7. 结束状态

写清结尾人物位置、摄影机朝向、道路延伸方向和下一镜可接的视觉锚点。结束帧必须仍然结构清楚，避免云雾完全遮挡或人物走出画面。

### 8. 连续性与防漂移

在同一段末尾写入：

- 不新增或删除人物、宫殿、浮岛、瀑布、门洞和天体。
- 宫殿不呼吸、不融化，柱体和檐线不弯曲。
- 人物不滑行、不换衣、不变脸、不复制、不出现畸形肢体。
- 摄影机不抖动、不跳帧、不突然改变焦段、曝光和光向。
- 水流不改道，倒影不漂移，纹理不闪烁。
- 不出现文字、水印和标志。

只保留当前镜头相关项，不把段尾变成长篇通用否定词表。

## 运动预算

| 元素 | 默认强度 | 说明 |
| --- | --- | --- |
| 摄影机位移 | 低到中 | 5 秒内完成一次推进、横移、弧线或升高 |
| 摄影机旋转 | 很低 | 仰角变化通常不超过约 8–12 度 |
| 人物步行 | 低 | 2–5 步，远景人物不做复杂表演 |
| 衣袂与发丝 | 低到中 | 一次主风浪加持续微动 |
| 云海 | 很低 | 大尺度缓慢翻涌，不高速滚动 |
| 天河与瀑布 | 中 | 沿固定河道连续运动 |
| 白鸟 | 低 | 一小群穿过尺度参照，不贴近镜头 |
| 光线 | 很低 | 一次柔和增强或移动，不闪烁 |
| 巨构 | 静止 | 只允许真实浮尘、水汽和光影变化 |

若供应商运动强度只有低、中、高三个档位，默认选低或中；高运动只用于明确的暴雨穿越或高速飞行，不用于仪式性天宫。

## 视差与揭示节拍

有效揭示示例：摄影机向右横移，近景朱柱快速向左滑出，中景人物缓慢前进，远景月内天门几乎不移动；柱子离开后，原先被遮挡的巨月边缘出现，观众才意识到门体只是月轮内部的一小部分。

无效揭示：整幅画面均匀放大、突然爆光、云雾瞬间消失、宫殿从无到有凭空生成。

## 人物和环境运动

- 人物步幅与地面比例匹配，脚底不穿透桥面。
- 浅水对脚步作局部反馈，不让整片镜海剧烈波动。
- 披风顺主风方向运动，不能与云、飞尘和水雾风向相反。
- 白鸟在极远处只需 3–8 只，保持尺寸小且路径简单。
- 云海运动方向服务构图：让开终点，而不是反复遮挡主奇观。
- 体积光随云层遮挡缓慢变化，亮度不超过主体细节承受范围。

无人场景通过前景云、天河、白鸟、光线和摄影机制造运动。不要为了“有变化”让宫殿旋转、月亮快速移动或浮岛上下弹动。

## 连续性与防漂移

连续镜头复述：人物左右关系、衣着颜色、天河流向、光线方向、终极宫阙位置和主行动方向。若有相邻结束帧，把上一镜终点设置为下一镜前景或视线方向。

使用首尾帧工具时：首帧锁定当前通过图，尾帧只在构图已明确且与下一镜连续时提供。不要用差异过大的首尾帧强迫模型完成不可实现的空间变换。

## 可复制模板

将花括号替换为本镜事实，删除字段名并合成一个单段：

```text
以输入图片为唯一首帧和视觉基准，锁定{主奇观、建筑结构、人物服饰比例、光向、道路和留白}，摄影机从{起点}以{低或中等速度}沿{单一主轨迹}向{方向}移动，并在{时间点}完成{轻微辅助俯仰或横移}；{人物}执行{一个主动作与一个细节动作}，保持{朝向、脚底接触、不露脸与结束姿态}；前景{元素与较快运动}，中景{元素与中速运动}，远景{元素与低速运动}，{巨构稳定项}保持绝对刚性，以前景快、中景中、远景慢的真实视差逐步揭示{不可能关系}；在片段{60%–85%}处通过{越过遮挡、光线变化或白鸟尺度事件}形成情绪峰值，结尾停在{人物位置、摄影机方向、连续道路与下一镜锚点}；全过程保持{人物、建筑、材质、天河流向、光线和色彩连续性}，不新增{元素}，不发生{当前镜头高风险的结构漂移、人物变形、镜头抖动、错误水流、过曝、文字水印}。
```

## 自检

- 是否只有一个无空行的单段？
- 是否明确首帧锁定，而不是只写“保持一致”？
- 摄影机是否只有一个主轨迹？
- 人物是否只有一个主动作？
- 前中远是否有速度递减的分层环境运动和视差？
- 是否在明确时间点完成一次揭示？
- 结束状态是否能连接下一镜？
- 是否明确巨构保持稳定？
- 防漂移是否针对当前镜头，而非复制通用否定词表？
