# 天宫奇观镜头库

## 使用方法

每个镜头选择一个原型作为主奇观，可以借用另一个原型的尺度参照，但不能把两个主关系平铺在同一画面。连续六镜至少使用三种构图、三种摄影机运动和两种空间关系。

## 六镜头默认组合

### 朝圣型

`W01 月内天门 → W02 天河托城 → W03 镜海预言 → W05 月内天路 → W10 山河门钉 → W12 门后第二天`

适合人物同行、旧约、寻找和抵达。奇观从入口升级到尺度反转。

### 无人天体型

`W06 星海瀑布 → W04 通天神柱 → W08 日轮宫环 → W07 倒悬天阙 → W11 天宫穿星 → W12 门后第二天`

使用白鸟、窗格、山峰和天体建立尺度，不强行加入人物。

### 风雨穿越型

`W04 通天神柱 → W09 云涡神阶 → W02 天河托城 → W05 月内天路 → W11 天宫穿星 → W12 门后第二天`

适合单人、竖屏、暴雨后放晴。控制高速运动只出现在前两镜。

## 构图轮换

六镜不要重复同一种“人物居中、宫殿在远方”：

1. 偏置巨构：主奇观集中左或右，另一侧保留有效留白。
2. 中央仪式轴：只用于入口、镜海或抵达。
3. 单侧框景：柱列或门柱只占一侧，另一侧开放。
4. 弧形路径：桥、天路或河道跨越云海。
5. 上方压框：倒悬宫阙或云涡占上部，人物空间在下部。
6. 极端尺度反转：前景细节滑开后显露整体。

## 转场锚点

- 门洞：上一镜进入门洞，下一镜从门内阴影向外看。
- 光向：上一镜右后方金光，下一镜仍从右后方照入。
- 水流：上一镜倒流天河进入云层，下一镜从同一河道内部观察。
- 路径：上一镜桥面指向右上，下一镜前景路径从左下继续。
- 颜色：朱砂披风或暗金门缝作为跨镜点睛色。
- 声音：钟声、低频风、远雷和水声可以先于画面进入下一镜。

## 选型禁区

- 不在同一镜同时使用月内天门、天河托城、日轮宫环和星海瀑布。
- 不连续三镜使用中央对称构图。
- 不让第 6 镜的规模小于第 5 镜；抵达必须打开更大的空间或更深的情绪。
- 不使用会直接模仿具体影视、游戏或艺术家的独特造型。
